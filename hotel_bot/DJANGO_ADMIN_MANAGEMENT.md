# مدیریت ادمین‌های Django از طریق ربات تلگرام

## معرفی

این سیستم امکان مدیریت کامل ادمین‌های وبسایت Django را از طریق ربات تلگرام فراهم می‌کند. 

## تفاوت ادمین‌های ربات و ادمین‌های Django

### ادمین‌های ربات (Bot Admins)
- در فایل `admins.json` ذخیره می‌شوند
- دسترسی به خود ربات تلگرام دارند
- با `user_id` تلگرام شناسایی می‌شوند
- از طریق سیستم گروه‌بندی ربات مدیریت می‌شوند

### ادمین‌های Django (Website Admins)
- در دیتابیس Django ذخیره می‌شوند
- دسترسی به پنل ادمین وبسایت دارند
- با `BaseUser` و مدل `Admin` مدیریت می‌شوند
- از سیستم `Groups` و `Permissions` Django استفاده می‌کنند

## امکانات مدیریتی

### 1. مشاهده لیست ادمین‌های Django
- نمایش تمام ادمین‌های سایت
- نمایش وضعیت (فعال، Staff، Superuser)
- دسترسی سریع به جزئیات هر ادمین

### 2. مدیریت جزئیات ادمین
برای هر ادمین می‌توانید:
- **اطلاعات پایه**: نام، شماره تلفن، ID
- **وضعیت‌ها**: Active, Staff, Superuser
- **گروه‌های Django**: مشاهده و ویرایش عضویت در گروه‌ها
- **مجوزهای مستقیم**: مشاهده و مدیریت permissions

### 3. مدیریت گروه‌های Django
- مشاهده لیست گروه‌های Django
- افزودن/حذف ادمین از گروه‌ها
- مشاهده اعضای هر گروه
- مشاهده مجوزهای هر گروه

### 4. تنظیمات پیشرفته
- **تبدیل به Staff**: دادن دسترسی به پنل ادمین Django
- **تبدیل به Superuser**: دادن دسترسی کامل (فقط توسط سوپرادمین‌های ربات)
- **فعال/غیرفعال کردن**: کنترل دسترسی ادمین به سیستم
- **حذف ادمین**: حذف کامل از سیستم

### 5. مدیریت OTP
- ایجاد توکن‌های Static برای ورود دو مرحله‌ای
- مشاهده توکن‌های موجود
- تازه‌سازی و حذف توکن‌ها

## دسترسی به امکانات

از منوی اصلی ربات:
1. **کنترل پنل** ← **مدیریت ادمین‌های وبسایت Django**

یا برای OTP:
1. **کنترل پنل** ← **مدیریت ادمین‌های بات** ← **مدیریت توکن‌های OTP**

## نکات امنیتی

⚠️ **توجه مهم**: 
- فقط کسانی که دسترسی `manage_admins` در ربات دارند می‌توانند ادمین‌های Django را مدیریت کنند
- تبدیل به Superuser فقط توسط سوپرادمین‌های ربات امکان‌پذیر است
- تغییرات بلافاصله در دیتابیس Django اعمال می‌شوند

## ساختار فایل‌ها

```
hotel_bot/
├── django_admin_manager.py   # مدیریت ادمین‌های Django
├── otp_manager.py            # مدیریت OTP ادمین‌های Django
├── admin_manager.py          # مدیریت ادمین‌های ربات
├── bot.py                    # هندلرهای اصلی ربات
└── menu_manager.py          # منوهای ربات
```

## استفاده در کد

### نمایش منوی ادمین‌های Django:
```python
from hotel_bot.django_admin_manager import DjangoAdminManager

await DjangoAdminManager.show_django_admins_menu(chat_id, context)
```

### نمایش جزئیات یک ادمین:
```python
await DjangoAdminManager.show_django_admin_detail(chat_id, context, base_user_id)
```

### مدیریت گروه‌های یک ادمین:
```python
await DjangoAdminManager.manage_admin_groups(chat_id, context, base_user_id)
```

## Callback Handlers در bot.py

هندلرهای زیر به `bot.py` اضافه شده‌اند:

- `django_admins_menu`: نمایش لیست ادمین‌ها
- `django_admin_detail:{id}`: جزئیات ادمین
- `manage_django_admin_groups:{id}`: مدیریت گروه‌ها
- `toggle_group:{user_id}:{group_id}`: افزودن/حذف از گروه
- `toggle_django_admin:{id}`: فعال/غیرفعال کردن
- `django_groups_menu`: لیست گروه‌های Django
- `django_group_detail:{id}`: جزئیات گروه
- `manage_django_admin_perms:{id}`: مدیریت مجوزها
- `make_staff:{id}`: تبدیل به Staff
- `make_superuser:{id}`: تبدیل به Superuser

## مثال‌های کاربردی

### سناریو 1: افزودن ادمین جدید به سایت
1. یک `BaseUser` در Django ایجاد کنید
2. یک `Admin` مرتبط با آن بسازید
3. از طریق ربات ادمین را به گروه مورد نظر اضافه کنید
4. در صورت نیاز، توکن‌های OTP ایجاد کنید

### سناریو 2: تغییر دسترسی‌های یک ادمین
1. منوی **مدیریت ادمین‌های Django** را باز کنید
2. ادمین مورد نظر را انتخاب کنید
3. **مدیریت گروه‌ها** را انتخاب کنید
4. گروه‌های مورد نظر را فعال/غیرفعال کنید

### سناریو 3: غیرفعال کردن موقت یک ادمین
1. جزئیات ادمین را باز کنید
2. دکمه **غیرفعال کردن** را بزنید
3. ادمین نمی‌تواند به سایت دسترسی داشته باشد
