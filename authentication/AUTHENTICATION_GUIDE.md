# راهنمای کامل سیستم احراز هویت و مدیریت دسترسی‌ها

## 📚 ساختار سیستم

### 1. کاربران عادی سایت (NaturalProfile)

- 🟢 کاربران معمولی که از سایت ثبت‌نام می‌کنند
- ورود: با OTP (کد یکبار مصرف پیامکی)
- دسترسی: فقط به پنل کاربری
- مدیریت: از بخش "کاربران" در پنل ادمین

### 2. ادمین‌های سایت (Admin)

- 🟡 مدیران با دسترسی‌های محدود و قابل تنظیم
- ورود: با OTP به پنل کاربری (مثل کاربران عادی)
- دسترسی: بر اساس Groups و Permissions
- مدیریت: از بخش "ادمین‌ها" در پنل ادمین
- **نمی‌توانند به پنل ادمین جنگو دسترسی داشته باشند**
- می‌توانید از کاربران عادی، ادمین بسازید

### 3. ادمین‌های جنگو (SuperUser)

- 🔴 دسترسی کامل به تمام سیستم
- ورود: شماره موبایل + رمز عبور
- دسترسی: کامل به پنل ادمین جنگو
- **فقط از طریق ترمینال قابل مدیریت**
- در پنل ادمین نمایش داده نمی‌شود

---

## 🔧 دستورات مدیریتی

### ساخت یا تنظیم رمز SuperUser

```bash
# در محیط محلی
python3 manage.py create_superuser_admin --phone 09123456789 --password your_strong_password

# در Docker
docker exec -it django_app python manage.py create_superuser_admin --phone 09123456789 --password your_strong_password
```

### لیست کردن SuperUser ها

```bash
# در محیط محلی
python3 manage.py list_superusers

# در Docker
docker exec -it django_app python manage.py list_superusers
```

### ساخت گروه‌های پیش‌فرض

```bash
# در محیط محلی
python3 manage.py setup_default_groups

# در Docker
docker exec -it django_app python manage.py setup_default_groups
```

این دستور این گروه‌ها را می‌سازد:

- 📝 مدیر محتوا (بلاگ، صفحات)
- 💰 مدیر مالی (کیف پول، تراکنش‌ها)
- 👥 مدیر کاربران (پروفایل‌ها، احراز هویت)
- 💬 پشتیبان (پیام‌ها، نوتیفیکیشن)
- 🏨 مدیر رزرواسیون (هتل‌ها، اتاق‌ها)

## 📋 نحوه کار با سیستم

### 1. ساخت ادمین جنگو (SuperUser) - از ترمینال

```bash
python3 manage.py create_superuser_admin --phone 09123456789 --password MyPassword123
```

### 2. ساخت ادمین سایت (Admin) - از پنل ادمین

#### مرحله 1: تنظیم دسترسی‌های کاربر

1. وارد پنل ادمین جنگو شوید (با SuperUser)
2. به `Authentication > کاربران` بروید
3. کاربر مورد نظر را پیدا کنید
4. **Groups**: یک یا چند گروه به کاربر اختصاص دهید (مثلاً "مدیر محتوا")
5. **User permissions**: دسترسی‌های خاص اضافی (در صورت نیاز)
6. ذخیره کنید

#### مرحله 2: ساخت پروفایل ادمین

1. به `Authentication > ادمین‌ها` بروید
2. "افزودن ادمین" کلیک کنید
3. کاربر را انتخاب کنید
4. نام، عکس و سایر اطلاعات را وارد کنید
5. پترن‌های پیامکی را تنظیم کنید (اختیاری)
6. ذخیره کنید

### 3. مدیریت گروه‌های دسترسی

#### ساخت گروه جدید

1. به `Authentication and Authorization > Groups` بروید
2. "افزودن گروه" کلیک کنید
3. نام گروه را وارد کنید (مثلاً "مدیر بلاگ")
4. دسترسی‌های مورد نیاز را انتخاب کنید
5. ذخیره کنید

#### گروه‌های پیش‌فرض موجود

- 📝 **مدیر محتوا**: بلاگ، صفحات، تنظیمات عمومی
- 💰 **مدیر مالی**: کیف پول، تراکنش‌ها، باشگاه مشتریان
- 👥 **مدیر کاربران**: پروفایل‌ها، احراز هویت
- 💬 **پشتیبان**: تماس‌ها، پیام‌ها، چت
- 🏨 **مدیر رزرواسیون**: رزرو، هتل‌ها، اتاق‌ها

### 4. گروه‌بندی اپلیکیشن‌ها

به `Authentication > گروه‌های اپلیکیشن` بروید تا اپلیکیشن‌ها را گروه‌بندی کنید:

- مدیریت محتوا 📝
- مالی 💰
- مدیریت کاربران 👥
- رزرواسیون 🏨
- تنظیمات ⚙️
- ارتباطات 💬

## 🔐 امنیت

- ❌ **SuperUser از پنل ادمین حذف شده** - فقط از ترمینال قابل مدیریت
- ✅ **Admin ها رمز عبور ندارند** - فقط با OTP وارد می‌شوند
- ✅ **جداسازی کامل**: کاربران / ادمین‌های سایت / ادمین‌های جنگو
- ✅ **کنترل دسترسی دقیق** با Groups و Permissions
- ✅ **is_staff فقط برای SuperUser** - Admin ها به پنل ادمین جنگو دسترسی ندارند

## ⚠️ نکات مهم

1. **SuperUser**: همیشه از رمز قوی استفاده کنید
2. **Admin**: می‌توانید از کاربران عادی ادمین بسازید
3. **Groups**: ابتدا `setup_default_groups` را اجرا کنید
4. **Permissions**: دسترسی‌ها را به Groups اختصاص دهید، نه مستقیم به کاربران
5. **امنیت**: SuperUser فقط برای مواقع ضروری استفاده شود
